Repères pour gérer D1 dans Cloudflare

  • Ouvre Cloudflare → Storage & databases → D1 SQL Database → snt-evaluation → Console.
  • Pour consulter les sessions : SELECT * FROM sessions ORDER BY created_at DESC;
  • Pour consulter les sujets : SELECT id, title, description, is_active FROM subjects;
  • Pour consulter les tentatives : SELECT * FROM attempts ORDER BY started_at DESC;
  • Pour compter les sessions : SELECT COUNT(*) FROM sessions;
  • Pour modifier le nom ou la durée d'une session (remplacer le code) : 
    UPDATE sessions
SET title = 'Nouveau nom',
    duration_minutes = 50
WHERE code = 'ABC123';
  • Pour désactiver un sujet sans le supprimer : 
    UPDATE subjects
SET is_active = 0
WHERE id = 'IDENTIFIANT';

Conseil : privilégie les boutons de cette page. Avant toute requête SQL de modification ou suppression, vérifie la table et fais une copie de sauvegarde. Une suppression de session efface aussi ses tentatives et son journal d'événements.

Mode d’emploi — gérer les interrogations et les TP notés

1. Importer un sujet

Dans « Importer des sujets », sélectionne le fichier JSON préparé pour le TP ou l’interrogation, puis importe-le. Le sujet est conservé dans la base et peut servir à créer plusieurs sessions. Il n’est pas nécessaire de le réimporter pour chaque classe ou date.

2. Créer une session

Choisis le sujet, donne un nom à la session et fixe la durée. Le réglage « Ordre des questions » permet de choisir :

  • Aléatoire (interrogation) : l’ordre des questions est mélangé individuellement pour chaque élève.
  • Ordre du sujet (TP noté) : tous les élèves retrouvent les questions dans l’ordre du fichier JSON.

Le mélange des propositions d’un QCM reste indépendant : les options peuvent être présentées dans un ordre différent selon les élèves. Le choix d’ordre des questions est enregistré pour la session et ne modifie pas le sujet importé.

3. Distribuer le code et gérer plusieurs demi-classes

La session est ouverte dès sa création. Communique le code aux élèves uniquement lorsque tu souhaites commencer. Pour deux demi-classes passant à des dates différentes, tu peux utiliser la même session : ferme-la après la première demi-classe, puis rouvre-la le jour de la seconde. Les tentatives déjà enregistrées sont conservées et les nouveaux élèves utilisent le même code.

Attention : fermer une session empêche les nouveaux élèves de commencer, mais n’interrompt pas de force les tentatives déjà en cours. Si tu souhaites des résultats séparés par demi-classe, crée plutôt deux sessions distinctes à partir du même sujet.

4. Consulter les résultats

Dans « Résultats », saisis le code de session, puis actualise. Tu peux consulter les notes, les états, les alertes et le journal des événements, ou exporter les résultats au format CSV.

5. Fermer, rouvrir ou supprimer

  • Fermer / Rouvrir : bloque ou autorise les nouvelles connexions. Cela ne supprime aucune donnée.
  • Modifier : permet de changer le titre et la durée de la session. La modification de durée ne change pas le délai déjà attribué aux élèves ayant commencé.
  • Supprimer : efface définitivement la session, les tentatives, les notes et les événements associés. Cette action est irréversible.

6. Gérer les sujets et la base D1

Dans « Gestion de la base de données », tu peux modifier les titres/descriptions des sujets. La suppression d’un sujet est refusée tant qu’une session lui est associée. Pour les opérations directes dans Cloudflare D1, privilégie les consultations SQL ; avant toute modification ou suppression, réalise une sauvegarde et vérifie soigneusement la requête.

Le jeton ADMIN_TOKEN doit rester confidentiel : ne le place jamais dans le dépôt GitHub ni dans un fichier distribué aux élèves.
